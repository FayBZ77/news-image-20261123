# The world on Monday 23 November 2026, in one image

`entry.png` (1024x1024) is a newspaper front page summing up the world's news of
Monday 23 November 2026. `main.ts` (the kit's starter driver) copies it to
`/output/entry.png`; `make_image.py` is the PIL program that drew it.
